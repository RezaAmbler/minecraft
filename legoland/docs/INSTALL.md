# Install — LEGOLAND California

A private family Minecraft Java world. Built for client **26.1.2** (the world is written
at 1.21.8 and upgrades automatically on first load — this is expected).

## 1. The world (includes the datapack)
1. Unzip `LegolandCalifornia-world.zip`.
2. Move the `LEGOLAND California` folder into your Minecraft `saves/` folder:
   `~/Library/Application Support/minecraft/saves/` (macOS).
3. Launch Minecraft **26.1.2**, open the world ("LEGOLAND California"). It loads in Creative.

## 2. The resource pack (optional theming)
1. Copy `LegolandCalifornia-resourcepack.zip` into `resourcepacks/`.
2. In game: Options → Resource Packs → enable "LEGOLAND California".

## 3. Ride the coasters!
- You spawn at **The Beginning** (the park entrance).
- Type `/function legoland:menu` (chat) — a clickable menu appears.
- Click **Ride a coaster** → pick one (The Dragon to start).
- You hop into the coaster train on the track and ride. Click **Exit ride** to stop.
- **Travel to a land** in the menu teleports you around the park.

It is always bright, sunny, peaceful, Creative — safe for young explorers.

See TESTING.md for what to check / report. Private/family build — please don't redistribute.
