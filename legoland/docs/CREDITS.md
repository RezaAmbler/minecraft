## Committed reference inputs (`references/`)
- **`dem_grid.csv`, `anchors_elev.csv`** — elevation from the **USGS 3DEP** dataset via the USGS
  Elevation Point Query Service (epqs.nationalmap.gov), sampled 2026-06-07. **Public domain** (US
  Government work).
- **`osm_legoland.json`** — park footprint, paths, and water features from **OpenStreetMap** via the
  Overpass API. © OpenStreetMap contributors, licensed under the **Open Database License (ODbL)**.
  Used here as a geometry reference for a private build.
