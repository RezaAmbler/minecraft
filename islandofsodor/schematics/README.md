# schematics/

Generated `.schem` (Sponge schematic) structure library, exported by the Phase 4 structure
code via `mcschematic`. These are reusable building blocks (stations, sheds, docks, bridges,
tunnels) that the placement engine stamps into the world.

Regenerable from `src/structures/`. `.schem` files carry a 1.21.5 DataVersion (mcschematic's
newest 1.21 enum); harmless — block states are identical across 1.21.x (see DECISIONS D5).
