# Install — Island of Sodor

A Minecraft Java world for the family. Built for client **26.1.2** (the world is written
at 1.21.8 and upgrades automatically on first load — this is expected).

## 1. The world (includes the datapack)
1. Unzip `IslandOfSodor-world.zip`.
2. Move the `Island of Sodor` folder into your Minecraft `saves/` folder:
   `~/Library/Application Support/minecraft/saves/` (macOS).
3. Launch Minecraft **26.1.2**, open the world ("Island of Sodor"). It loads in Creative.

## 2. The resource pack (optional theming)
1. Copy `IslandOfSodor-resourcepack.zip` into `resourcepacks/`.
2. In game: Options → Resource Packs → enable "Island of Sodor".

## 3. Ride the engines!
- You spawn at **Knapford** (the central station).
- Type `/function sodor:menu` (chat) — a clickable menu appears.
- Click **Ride an engine** → pick one (Thomas, Edward, Henry, Gordon, James, Percy, Toby).
- You hop into the engine on the track and ride the loop. Click **Put engine away** to stop.
- **Travel to a station** in the menu teleports you between stations.

It is always bright, sunny, peaceful, Creative — safe for young explorers.

See TESTING.md for what to check / report. Enjoy Sodor! 🚂
